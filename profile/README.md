Welcome to the GitHub organization for CSC675/775 Sections 02 and 03 · Introduction to Database Systems at San Francisco State University.

This organization supports the course's engineering environment and provides enrolled students with access to the resources and repositories used throughout the semester.

## About the Course

CSC675/775 explores the design and implementation of relational database systems through a semester-long engineering project.

Students progress from database requirements and conceptual modeling through relational design, normalization, PostgreSQL implementation, database logic, transactions, concurrency, indexing, security, ORM development, testing, and application integration.

The course combines database fundamentals with modern software engineering practices, Git-based development, and AI-assisted engineering.

## AI-Assisted Engineering

Software engineering is changing as AI becomes integrated directly into the tools engineers use to design, implement, test, review, and maintain software. CSC675/775 incorporates that shift into the development environment rather than treating AI as a separate topic.

Students work with AI assistance during selected stages of the engineering process, including research, design review, implementation, debugging, testing, and verification. The amount of assistance permitted depends on what the activity is intended to teach. Some engineering decisions and implementations remain student-owned; other activities deliberately allow substantial AI assistance.

The goal is not to replace database reasoning with generated output. Students learn to work in an AI-integrated engineering environment while remaining responsible for the system they build. They are expected to inspect generated work, test it against the actual database, identify incorrect assumptions, make engineering decisions, and explain the resulting implementation.

The course follows a practical engineering cycle:

**THINK → GENERATE → INSPECT → EXPLAIN → CORRECT → VERIFY**

This reflects an increasingly important skill in software development: knowing not only how to use AI tools, but when to use them, how much authority to give them, and how to verify their work before it becomes part of a real system.

## Access

Course repositories are private and available only to enrolled students and authorized instructional staff.

Students receive organization access using the GitHub account registered through the course Canvas page.

If you are currently enrolled in CSC675/775 and cannot access the course resources, please verify that:

- You submitted the correct GitHub username through Canvas. 
- You accepted the GitHub organization invitation.
- You are signed in to GitHub using the account you registered for the course.

For course policies, announcements, grades, and access information, please use the official Canvas course.
